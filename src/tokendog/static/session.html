sort:

What entered the window at each turn, and what it cost afterwards: its size times the number of later turns that re-read it. Nothing re-reads it deliberately — the model is stateless, so every request carries the whole conversation again, and anything added early is paid for on every turn that follows. Rows are in time order by default, so row two follows row one; switch to costliest first to rank by carried cost.
